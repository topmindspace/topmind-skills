# 已知坑（实测踩过，写入质检与操作纪律）

## 1. `--embed-images` 不加 = 粘贴丢图

链路：HTML `src="images/xx.png"` → 浏览器复制序列化成 `file://` → 公众号后台取不到 → **整张 `<img>` 消失**（不是裂图）。

**修法**：`md2wechat.py --embed-images`（base64 内嵌）。`images/` 仍导出作占位符兜底。

自检：

```bash
grep -c 'src="images/' <包>/*-公众号版.html     # 期望 0
grep -c 'src="data:image/' <包>/*-公众号版.html  # 期望 = 正文图数
```

## 2. 图片 basename 撞名 → 链式全挂

`resolve_image()` 按 **basename** 复制到 `images/`。`images/bare/01.png` 与 `images/01.png` 同名 → 产出 `01-1.png` → 删副本 = HTML 图全挂。

**铁律**：

- 正文只引用 `images/XX.png`，包内只放正文那一套  
- 多套用不同前缀（`full-` / `bare-`），不要靠子目录区分  
- `-1` 副本不是垃圾，是 HTML 正在引用的文件  

自检：

```bash
find <包> -name "*-1.*"    # 不应有任何结果
```

## 3. 同一文件并行 Edit 只落盘一部分

同一条消息多个 Edit：工具可能都回 Successfully，**只有部分落盘**。

**纪律**：改完必须 `grep` 关键词复核；多处改动合成一个脚本一次写完，或串行分轮。

## 4. `::: stat` 非管道行被静默丢弃

容器内每行必须 `数值 | 说明`。不带 `|` 的行整块消失且无报错。生成 HTML 后抽查容器内容。

## 5. 表格单元格 `|` 要转义

生成 markdown 表时 `.replace(/\|/g, '\\|')`。JS 模板字符串里写 `\\\\|` 才得到 `\\|`。

## 6. 代码块长行被 `break-all` 词中切断

JSON 示例行宽压到 ~55 字符；真实节选注明「节选」，字段值不得改写。

## 7. 图文两套同名 + 清理 `bare/` 

完整版与纯图形版共处包内必撞名。完整版放研究层；交付包只留正文用的一套。

## 8. 外部工具改稿的数字漂移

「比值对但绝对值错」= 从别的口径倒推。先脚本回溯 `results/*.json`，再改文字。

## 9. 表格手抄必漂移

从数据源生成（脚本直出）。同一文档两份拷贝时 `md5` 比对；派生汇总字段也是数据，要回填。

## 10. qu-aiwei 误报别改坏

- 「排比三段式」可能误报数据变化（从 A 到 B）→ **保留**  
- 专有名词「复盘」→ 不改；动词套话 → 改  

## 11. 满分仍「太 AI」

词面 100 分只证明无套话。再查四症状：段末金句癖 / 节奏过分整齐 / 没有「我」与场景 / 报告体标注。

## 12. 加「人味」用力过猛

社交垫词（「先说个好消息」「说白了」）不是人味。判据：删掉后读者少知道了什么？

## 13. 长文零容器 = 视觉窒息

每 1500–2500 字至少一个 `::: stat` 或 `::: pull`。8000 字纯段落反面教材。

## 14. 复制依赖 `execCommand`

Safari 可能失败 → 手动全选复制。Desktop/移动端提供按钮 + 失败提示。

## 15. 合规自检误报

- 正文 `<h2>` 是有意设计（不用 h1）  
- `pre` 会命中英文单词；只在 `<article>` 内按标签形式匹配
